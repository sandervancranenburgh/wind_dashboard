# Meteocons weather assets

These 128×128 transparent PNGs were rasterized from the `fill` variants in
`@meteocons/svg-static@0.1.0`.

- Upstream: https://github.com/basmilius/meteocons
- Package: https://www.npmjs.com/package/@meteocons/svg-static/v/0.1.0
- License: MIT; see `LICENSE` in this directory.
- Conversion: CairoSVG 2.9.1 with a 128×128 output canvas.

Only assets referenced by `weather_conditions.py` are vendored.
